# 讯飞翻译机 4.0 快速入门指南

> 适用范围：讯飞翻译机 4.0 标准版/星火版，中国大陆版。本资料基于公开官方产品页和官方 FAQ 整理；不同地区、其他型号或后续系统版本的界面与能力可能不同。

## 一、开机后先做什么

1. 开机后，从屏幕底部向上轻滑解锁。
2. 解锁完成后，设备会进入语音翻译界面。
3. 在语音翻译界面从屏幕下方上滑，可选择需要的翻译语种。

首次解锁并不等于必须先连接 WiFi。在线翻译、系统更新、购买全球上网流量卡和下载新的离线包需要网络；已下载的离线包可在无网络时使用。

## 二、第一次进行语音翻译

设备支持自动模式和手动模式：

- 自动模式：按界面引导将设备靠近嘴边说话，结束后移开设备，系统会显示并播报译文。
- 手动模式：点击或按住界面上的语音输入按钮说话。

面对面交流时，可从语音翻译界面左侧边缘向右轻滑，进入面对面翻译界面。

## 三、提前准备离线翻译

离线翻译需要在有网络时准备语言包。翻译机 4.0 的语音翻译支持普通话与 16 种语言离线互译；官方产品页也将其表述为“17 种语言无网络翻译”（包含中文普通话）。

进入路径：语音翻译页面 → 右下角三点 → 更多设置 → 离线包管理。

默认已安装的离线包包括中英、中日、中韩、中西、中俄、中泰、中越。出行前请按实际目的地检查所需离线包是否已安装。

## 四、连接网络

### WiFi

在设备“设置”中的网络相关选项连接可用 WiFi。请以设备当前系统实际显示的菜单名称为准。

公共 WiFi 是否需要网页认证、以及认证页能否在设备上正常完成，取决于网络提供方和系统环境；本资料不将其视为已保证支持的设备能力。

### 全球上网流量卡

翻译机 4.0 标准版/星火版可从设备负一屏进入：全球上网 → 我的卡片 → 购买流量卡。选择目的地国家和使用天数后完成支付。

流量卡按 24 小时计费。购买后需在 30 天内到达目的地使用，超过有效期会失效且不予退费。该规则针对已购买的全球上网流量卡，不是设备首次开机激活规则。
