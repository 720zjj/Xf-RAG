# 讯飞翻译机 4.0 产品功能说明

> 本文仅覆盖中国大陆版的讯飞翻译机 4.0 标准版/星火版，不适用于翻译机 2.0、3.0、双屏翻译机或国际版。不同版本不能共用语种数量、系统路径或硬件规格。

## 一、翻译能力

### 1. 在线语音翻译

- 官方产品页标注支持 85 种语言在线翻译，覆盖近 200 个国家和地区。
- 支持双语自动识别、面对面翻译和语音播报等能力。
- 在线翻译依赖可用网络；网络质量会影响实际响应速度和结果。

### 2. 离线语音翻译

- 官方产品页标注支持 17 种语言无网络翻译。
- 官方 FAQ 的具体口径为：中文普通话与英语、日语、韩语、俄语、法语、西班牙语、德语、意大利语、葡萄牙语、阿拉伯语、越南语、泰语、印地语、印尼语、维吾尔语、藏语共 16 种语言离线互译。
- 离线包需要提前在联网状态下通过“语音翻译 → 右下角三点 → 更多设置 → 离线包管理”准备。

### 3. 拍照翻译与 AI 读图

- 官方产品页标注支持 32 种语言拍照翻译。
- 支持对拍摄内容进行图文翻译与问答交互；实际识别效果会受文字清晰度、拍摄角度和光线影响。

### 4. 行业翻译

支持 16 种中英在线行业翻译能力，包括外贸、医疗、金融、计算机、法律、能源、电力、信息技术、化学化工、材料科学、机械工业、汽车工业、船舶工业、道路工程和文艺传媒等。该能力仅适用于中英在线翻译场景。

## 二、连接与共享

### 1. WiFi 与移动网络

设备可通过设置中的网络相关选项连接 WiFi；菜单名称应以当前系统为准。本资料不承诺支持隐藏网络或酒店、机场等公共 WiFi 的网页认证流程。

设备可使用实体 SIM 卡或设备内购买的全球上网流量卡联网。全球上网流量卡需要选择目的地国家和使用天数，按 24 小时计费；购买后应在 30 天内到达目的地使用。

### 2. 蓝牙与热点

- 翻译机 4.0 标准版/星火版支持蓝牙 5.0 及以上耳机。
- 可在“设置 → 网络与连接 → 蓝牙”中开启蓝牙并配对设备。
- 当设备插入 SIM 卡或正在使用按天购买的全球上网流量卡时，可在“设置 → 网络与连接 → 共享热点”中开启热点。

## 三、需要避免的错误表述

- 不将“每日超过 300M 后限速”写为通用规则：当前公开官方页面未提供这一统一说明。
- 不将“购买后 30 天内激活”写为设备规则：30 天规则针对已购买的全球上网流量卡到达目的地使用。
- 不将“BLE 4.0”“翻译机 2.0/3.0/4.0 通用”写为 4.0 的产品规格。
