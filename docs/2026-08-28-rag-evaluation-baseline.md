## 本轮应如何判定结果

每题只填一个结论：`通过`、`部分通过`、`失败`。

除准确性外，重点记录以下项：

```text
第一句是否直接回答问题？       是 / 否
是否只使用当前 4.0 资料？       是 / 否
来源是否至少有一份期望资料？     是 / 否 / 未显示
该拒答或确认时是否这样做？       是 / 否 / 不适用
失败属于哪一类？                检索 / 生成 / 型号规则 / 安全规则 / 前端展示
```
