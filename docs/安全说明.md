# 讯飞翻译机 4.0 安全使用说明

> 适用范围：讯飞翻译机 4.0 标准版/星火版，中国大陆版。本文提供安全使用和风险处置建议；售后范围、维修方式和保修状态以设备绑定页及官方售后说明为准。

## 一、使用环境

- 官方 FAQ 建议设备在 -10℃ 到 50℃ 的环境中工作。
- 避免将设备置于温度或湿度变化剧烈的环境。
- 使用时保持麦克风区域无遮挡，以免影响语音识别效果。

## 二、进水或液体接触处理

如设备进水，或接触到饮料、化妆品等其他液体：

1. 立即停止使用，不要继续充电或反复开机测试。
2. 用干燥软布擦去表面液体，不要使用热风、微波炉等方式烘干。
3. 尽快通过官方售后渠道确认检测和维修方式。

本资料不对进液后的保修资格作预先判断，应以设备实际检测结论和售后规则为准。

## 三、系统操作风险

- 系统升级期间保持网络稳定，不要随意关机。
- 恢复出厂设置前先阅读设备提示，并备份需要保留的翻译记录。
- 设备无响应时，不要尝试未经官方确认的组合键或拆机操作。
- 不要自行拆开设备或更换内部部件（包括电池）；需要检修时请联系官方售后确认处理方式。
