# 讯飞翻译机 4.0 官方常见问题

资料来源：科大讯飞翻译机官方自助服务 H5「常见问题」。

稳定来源地址：https://h5.xftrans.cn/wechatServer/serverH5/entry/self-service.html#/faq-new

适用型号：翻译机 4.0 标准版/星火版（系统型号标识：翻译机4.0）。

核验日期：2026-09-01。

## 翻译机怎么切换翻译语言？

在语音翻译界面上，从屏幕下方往上滑，即可选择所需的语种。

## 翻译机 4.0 怎么使用语音翻译？

1. 开机后，从屏幕底部向上轻滑解锁。
2. 解锁后会直接进入语音翻译界面；在界面底部向上滑动可以设置语种。
3. 自动模式下，按界面引导将翻译机拿起并靠近嘴边说话，说完后移开设备，系统会显示并播报译文。
4. 关闭免按键翻译后，可点击屏幕底部按钮说话；如果开启“音量键变语音键”，也可按住机身右侧音量键说话，松开后翻译。

## 怎么切换面对面翻译的语种？

在面对面翻译界面，点击右下角三点，可以选择语种。

## 怎么进入面对面翻译？

在语音翻译界面上，从屏幕左侧边缘向右轻滑，即可切换至面对面翻译界面。

## 怎么进入拍照翻译？

打开翻译机进入首页，点击右上角可以进入拍照翻译，也可以在首页将屏幕向左滑动进入拍照翻译。

## 怎么下载离线语言包？

在语音翻译页面点击右下角三点，进入“更多设置 → 离线包管理”，提前下载所需离线语言包。

## 怎么切换翻译播报的男声或女声？

打开“设置 → 声音与振动 → 播报声音”，可以选择男声或女声。该功能仅支持官方 FAQ 列出的部分语种在线翻译时使用。

## 怎么调整翻译播报语速？

在语音翻译页面点击右下角三点，进入“更多设置 → 声音与振动 → 播报语速”。官方 FAQ 说明该功能仅支持中英文。

## 怎么连接蓝牙耳机？

进入“设置 → 网络与连接 → 蓝牙”，开启蓝牙开关，在设备列表中选择蓝牙耳机进行配对。翻译机 4.0 标准版/星火版支持蓝牙 5.0 及以上耳机。

## 怎么分享热点？

进入“设置 → 网络与连接 → 共享热点”开启开关。翻译机插卡或正在使用全球上网按天购买的流量卡时，可以向其他设备分享热点。

## 怎么恢复出厂设置？

进入“设置 → 系统 → 关于本机 → 恢复出厂”。恢复前请按照设备页面提示处理重要记录。

## 怎么跟外国人说第一句话？

下拉通知栏，点击“怎么跟外国人说第一句话”，即可一键播报。
