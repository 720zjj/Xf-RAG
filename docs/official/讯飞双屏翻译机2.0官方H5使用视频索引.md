1. 科大讯飞官方 H5 为讯飞双屏翻译机 2.0 提供《快速上手》使用视频。
2. 如现有有效文字资料已经提供完整的新机操作步骤，应先按文字步骤操作。
3. 如需查看设备画面演示，请在售后助手回答下方播放《快速上手》官方视频。
