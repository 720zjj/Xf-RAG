# 讯飞双屏翻译机 2.0 官方常见问题

资料来源：科大讯飞翻译机官方自助服务 H5「常见问题」、官方 H5 使用视频目录及科大讯飞官方产品资料。

## 双屏翻译机 2.0 可以翻译哪些国家的语言？

双屏翻译机 2.0 支持 80 多种外语在线翻译。科大讯飞官方资料说明，讯飞翻译机的跨语言服务覆盖近 200 个国家和地区；国家或地区本身不是语种，实际使用时应在设备语种列表中选择当地使用的语言。

离线翻译方面，语音翻译、会议会谈和旁听同传支持中文普通话与 17 种语言离线互译：英语、日语、韩语、西班牙语、俄语、泰语、越南语、法语、德语、阿拉伯语、意大利语、葡萄牙语、印地语、印尼语、土耳其语、维吾尔语、藏语。这里的“18 种语言离线翻译”包含中文普通话，所有离线包均已内置，无需联网下载。

在线语种的完整清单和可用方向可能随系统服务更新，以翻译机当前“语种列表”显示为准。

## 翻译机怎么切换翻译语言？

1. 打开翻译机，进入“语音翻译”。
2. 进入“语种列表”选择需要的语种功能；如希望设备自动判断语种，可选择“自动检测”。
3. 如果需要查看固定语种对的具体界面操作，请在售后助手回答下方播放双屏 2.0 官方《语音翻译》视频，并按照视频画面选择。

注意：官方常见问题明确给出了“语音翻译 → 语种列表 → 自动检测”的路径，但没有发布固定语种对的完整逐步文字说明；不应套用翻译机 4.0 的“屏幕下方上滑”路径，也不应套用旧翻译机 2.0 的实体按键说明。

## 多语种自动检测怎么使用？

1. 打开翻译机，进入“语音翻译 → 语种列表”。
2. 选择“自动检测”。
3. 自动检测仅支持在线使用，并且仅支持中文系统语言；选择自动语种识别后，自定义词库功能不可用。

## 自动语种判断错误怎么办？

在使用语音翻译的单按键自动语种判断时，如果语种判断错误，可切换翻译结果上方的语种方向按钮，设备会重新进行语种识别和翻译。

## 语音键怎么使用？

语音按键集成了机械按键与触摸感应芯片。默认设置下，按下实体按键会触发收音；在“语音翻译 → 高级设置”中打开“触控语音键”后，轻触按键也可触发收音。

## 强降噪模式收音不好怎么办？

拿翻译机时不要堵住任意一个麦克风。官方常见问题建议，在使用语音翻译强降噪模式时，距离翻译机约 15 cm 效果较好。

## 旁听同传怎么使用？

1. 打开翻译机，进入“旁听同传”。
2. 点击屏幕下方并选择正确的语种对，然后点击开始。
3. 录音过程中可以暂停；录音结束后可以保存记录，长按记录可以删除或重命名。
4. 点击右上角可进入高级设置，设置录音时不息屏以及双语对照、仅看中文或仅看外语等文本显示方式。

## 通话翻译怎么使用？

1. 打开翻译机并进入“通话翻译”，确保翻译机已经联网并打开蓝牙。
2. 在手机、平板或电脑上搜索并连接翻译机蓝牙设备。
3. 在翻译机屏幕下方选择正确的语种对，点击开始。

## 群组翻译怎么使用？

1. 打开翻译机并进入“群组翻译”，确保设备已联网。
2. 选择并添加语言，点击“创建会议室”。
3. 邀请参会人用微信或浏览器扫码加入；也可以把二维码分享给远程参会人。
4. 进入会议室后选择屏幕下方的语种，点击语音输入按钮开始聊天。

## 翻译播报怎么切换男声或女声？

进入“语音翻译 → 右上角高级设置 → 播报声音”，可以选择男声或女声。该功能仅支持官方 FAQ 列出的部分语种在线翻译时使用。

## 翻译播报语速怎么调整？

打开语音翻译，进入页面右上角“高级设置 → 语速”。官方 FAQ 说明该功能仅支持中英文。

## 怎么连接蓝牙耳机？

进入“设置 → 网络与连接 → 蓝牙”，开启蓝牙开关，在设备列表中选择蓝牙耳机进行配对。讯飞双屏翻译机 2.0 支持蓝牙 5.0 及以上耳机。

## 怎么设置息屏时间？

进入“设置 → 显示 → 息屏时间”，可以设置为 30 秒、1 分钟或 5 分钟。

## 怎么分享热点？

进入“设置 → 网络与连接 → 共享热点”开启开关。翻译机插卡或正在使用全球上网按天购买的流量卡时，可以向其他设备分享热点。

## 怎么恢复出厂设置？

进入“设置 → 系统 → 关于本机 → 恢复出厂”。恢复前请按照设备页面提示处理重要记录。

## 翻译机掉进水里还能用吗？

讯飞双屏翻译机 2.0 的 IP54 防水等级只用于防止各方向飞溅的水侵入，不代表可以浸水。设备掉进水里仍可能损坏；应停止继续使用并联系官方售后检查。

## 怎么跟外国人说第一句话？

在语音翻译页面点击“hi”按钮，即可播报。
