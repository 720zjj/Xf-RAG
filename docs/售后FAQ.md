# 讯飞翻译机 4.0 常见问题（FAQ）

> 适用范围：讯飞翻译机 4.0 标准版/星火版，中国大陆版。故障无法排除或设备存在安全风险时，请通过官方渠道联系售后；不要依据其他型号的组合键或菜单操作设备。

## 一、首次使用与翻译

### Q1：首次开机必须连接 WiFi 吗？

不一定。设备解锁后可直接进入语音翻译界面。在线翻译、系统更新、购买流量卡和下载离线包需要网络；已准备好的离线语言包可在无网络时使用。

### Q2：离线翻译支持哪些语言？

翻译机 4.0 的语音翻译支持中文普通话与 16 种语言离线互译。默认已安装中英、中日、中韩、中西、中俄、中泰、中越离线包；其余可在“语音翻译 → 右下角三点 → 更多设置 → 离线包管理”中检查和下载。

### Q3：翻译结果不准确怎么办？

请用正常语速连贯说话，避免把多句话合并为一句，并尽量减少背景噪声。若在线翻译异常，请先确认网络可用；若使用离线翻译，请确认已选择正确语种并安装对应离线包。

## 二、网络与全球上网

### Q4：无法连接 WiFi 怎么办？

先核对密码和网络本身是否可用，再在设备设置中的网络相关选项重新连接。酒店、机场等公共 WiFi 可能要求网页认证，但其兼容性取决于网络提供方与系统环境，本知识库不将其作为保证支持的能力。

### Q5：如何购买全球上网流量卡？

从设备负一屏进入“全球上网 → 我的卡片 → 购买流量卡”，选择目的地国家和使用天数后完成支付。流量卡按 24 小时计费；购买后需要在 30 天内到达目的地使用，过期失效且不予退费。

### Q6：可以分享热点吗？

可以。在设备插入 SIM 卡或正在使用按天购买的全球上网流量卡时，进入“设置 → 网络与连接 → 共享热点”开启热点并设置密码。

## 三、系统与设备

### Q7：设备卡住或无响应，如何强制重启？

当前公开官方 FAQ 未提供适用于翻译机 4.0 标准版/星火版的固定强制重启组合键。本知识库不应把其他型号的“电源键 + 音量键”写成 4.0 的确定操作。请先保持设备安全、连接充电线并通过官方售后确认处理方式。

### Q8：如何恢复出厂设置？

进入“设置 → 系统 → 关于本机 → 恢复出厂”。恢复前请阅读设备页面的提示，并先导出或备份需要保留的记录。

### Q9：如何更新系统？

进入“设置 → 系统与更新 → 系统更新”。升级前请确认网络可用；升级过程中不要中断网络或随意关机。

## 四、保修与售后

### Q10：保修期是多久？

请以绑定后的本机保修日期为准。可关注“讯飞翻译机”官方微信公众号，进入“我的 → 个人中心”，完成设备绑定后在“我的设备”查看本机保修日期。本知识库不将“统一一年保修”作为所有设备和销售地区都适用的固定结论。
