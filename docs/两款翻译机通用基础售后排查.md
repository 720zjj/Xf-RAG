# 讯飞翻译机 4.0 与双屏翻译机 2.0 通用基础售后排查

> 适用范围：讯飞翻译机 4.0 标准版/星火版与讯飞双屏翻译机 2.0。本文只提供不依赖型号专属菜单、不拆机、不刷机的外部基础检查。涉及强制重启组合键、拆机或系统刷写时，两款产品不能混用操作。

## 设备无法开机怎么办？

1. 先连接状态正常的充电线和适配器，为设备持续充电至少 10 分钟。
2. 充电后长按设备电源键尝试开机，并观察屏幕或指示灯是否有反应。
3. 若仍无反应，可分别更换已确认正常的充电线、适配器和插座后再试一次。
4. 如果设备曾进水、摔落，或出现异常发热、异味、鼓包，请停止充电和反复开机，将设备放在远离易燃物的安全位置并联系官方售后。
5. 完成上述外部检查后仍无法开机，请联系人工客服或官方售后检测；不要自行拆机，也不要套用其他型号的强制重启组合键。

## 设备充不进去电怎么办？

1. 检查插座、充电线和适配器是否正常，可分别更换已确认可用的配件重试。
2. 查看充电接口是否松动，接口内是否有明显灰尘或异物；不要使用金属物清理接口。
3. 保持设备和接口干燥。若设备异常发热、出现异味或始终无法充电，请停止充电并联系官方售后。

## 设备发热正常吗？

充电、持续联网或长时间使用时出现轻微温升，通常不代表设备故障。若温度持续过高、无法正常握持，或同时出现异味、鼓包、漏液等异常，请立即停止使用和充电，远离易燃物并联系官方售后检测。

## 设备没有声音怎么办？

1. 先确认设备没有处于静音状态，并逐步调高媒体音量。
2. 如果连接了蓝牙耳机或其他音频设备，先断开连接后再次播放翻译结果。
3. 重新播放一条已有的翻译结果，确认是单条内容无声还是所有内容都无声。
4. 若所有内容仍无声，请正常重启设备；仍未恢复时联系官方售后检测。
