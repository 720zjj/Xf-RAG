# 讯飞翻译机 4.0 用户操作手册

> 适用范围：讯飞翻译机 4.0 标准版/星火版，中国大陆版。界面名称会随系统更新变化，优先以设备当前页面为准。

## 第一章 语音翻译

### 1.1 进入翻译界面

开机后从屏幕底部向上轻滑解锁，设备会进入语音翻译界面。从屏幕下方上滑可选择语种。

### 1.2 自动模式与手动模式

- 自动模式：根据拿起、靠近嘴边和递出设备等动作触发收音、翻译和播报。
- 手动模式：点击或按住屏幕上的语音输入按钮说话。

### 1.3 面对面翻译

从语音翻译界面左侧边缘向右轻滑进入面对面翻译。双方可在屏幕不同区域进行交替说话；环境嘈杂时可改用手动模式。

### 1.4 拍照翻译

在设备首页点击右上角进入拍照翻译，也可以在首页向左滑动进入。拍摄前尽量让文字清晰、完整地出现在画面中；官方产品页标注支持 32 种语言拍照翻译。

## 第二章 离线翻译

### 2.1 支持范围

语音翻译支持中文普通话与 16 种语言离线互译。官方产品页的“17 种语言无网络翻译”包含中文普通话。

### 2.2 下载与管理离线包

在语音翻译页面点击右下角三点，进入“更多设置 → 离线包管理”。出行前在联网状态下检查所需语言包；下载完成后可在无网络环境下使用。

## 第三章 网络、蓝牙与热点

### 3.1 WiFi

通过设备设置中的网络相关选项连接 WiFi。在线翻译和系统更新需要网络；离线包已安装时，无网络仍可使用对应离线翻译能力。

### 3.2 全球上网

翻译机 4.0 标准版/星火版从负一屏进入“全球上网 → 我的卡片 → 购买流量卡”。选择目的地国家和使用天数后完成支付。

流量卡按 24 小时计费，购买后需在 30 天内到达目的地使用。不要将该规则理解为设备开机激活期。

### 3.3 蓝牙耳机

翻译机 4.0 标准版/星火版支持蓝牙 5.0 及以上耳机。进入“设置 → 网络与连接 → 蓝牙”，开启蓝牙后选择设备配对。

### 3.4 热点共享

插入 SIM 卡或使用按天购买的全球上网流量卡时，可进入“设置 → 网络与连接 → 共享热点”开启热点。

## 第四章 系统设置

### 4.1 更新系统

进入“设置 → 系统与更新 → 系统更新”。升级前检查网络，升级过程中避免中断网络或关机。

### 4.2 恢复出厂设置

进入“设置 → 系统 → 关于本机 → 恢复出厂”。操作前请阅读设备提示并备份重要记录。

### 4.3 设备无响应

公开官方 FAQ 未提供适用于翻译机 4.0 的固定强制重启组合键。请勿把其他型号的组合键当作确定操作；保持设备安全、连接充电线后，通过官方售后确认处理方式。
